Introduction In the field of array signal processing, direction of arrival (DoA) estimation determines the incident angle of the transmitted signal hitting an antenna array, realizing the localization of the signal emission source. It has wide applications in fields such as autonomous driving positioning, biomedical sensor signal analysis, and earthquake monitoring systems.
Existing classical DoA estimation methods (such as MUSIC, Root-MUSIC, ESPRIT, etc.) have significant limitations: they struggle to maintain high accuracy in complex scenarios with low signal-to-noise ratios, small source separations, coherent sources, or mismatched models; moreover, these methods rely on subspace decomposition operations such as eigenvalue decomposition (EVD) and singular value decomposition (SVD), which are computationally expensive and difficult to efficiently deploy in low-power embedded systems.
To overcome these shortcomings, research has recently shifted towards data-driven models like DeepMUSIC and SubspaceNet. Although these deep learning methods have improved robustness under low signal-to-noise ratios and multi-source scenarios, they still face critical issues: first, the "black box" nature makes it difficult to analyze, verify, and trust, not meeting the requirements of safety-critical systems; second, they overlook system-level complexity, leading to high costs in floating-point operations (FLOPs), training overhead, and device power consumption, hindering their application in edge computing.
Therefore, to simultaneously address the reliability issues of data-driven DoA estimators and system-level complexity problems, this paper proposes the use of hyperdimensional computation (HDC), a computational paradigm inspired by the brain. HDC addresses the above challenges by encoding information in high-dimensional vectors (hypervectors), allowing distributed representations that inherently tolerate noise, interference, and hardware differences; computation is achieved through simple large-scale parallel arithmetic operations (such as binding, aggregation, permutation). This inherent robustness combined with computational efficiency makes hyperdimensional computation an ideal choice for high-performance signal processing in low-power edge devices.
Based on this paradigm, this paper introduces HYPERDOA—a new hyperdimensional computation-based DoA estimator, transforming the theoretical advantages of hyperdimensional computation into practical systems. The main contributions are as follows:

The core of HYPERDOA is transforming DoA estimation into a pattern recognition problem that can be solved by hyper-dimensional computing. The overall architecture consists of four modular stages, with clear processes and efficient computation:
1. Feature extraction: It extracts compact feature vectors from raw signal snapshot matrices, supporting two methods adapted for complex scenarios:
   ✧  
   Average Spatial Lag Autocorrelation (Lag): First, calculate the sample space covariance matrix, then extract the average autocorrelation over each spatial lag to form a lag vector, which is normalized, separated into real and imaginary parts, and concatenated to obtain the real-valued feature vector, effectively characterizing spatial correlation at low dimensions;
   ✧  
   Spatial Smoothing: Divide the full antenna array into multiple overlapping subarrays, calculate the covariance matrices of each subarray and average them to recover the rank of the covariance matrix in coherent source scenarios. By vectorizing the upper triangular part, separating the real and imaginary parts, and concatenating, it effectively handles coherent signals.
Both methods require z-score normalization before inputting into a hyper-dimensional encoder.
2. Super-dimensional encoding uses a fractional power encoder based on Fourier Holography Reduction (FHRR), mapping low-dimensional feature vectors to high-dimensional supervectors (in this paper, dimension D=10000): Assigns unique random base supervectors (complex numbers on the unit circle) to each feature dimension, treating feature values as phase rotations acting on corresponding base supervectors. Through element-wise multiplication (binding), integrates all rotated base supervectors to generate the final query supervector - similar inputs will generate similar supervectors in the high-dimensional space.
3. The core of the associative memory is to store a set of prototype hypervectors (centroids), each corresponding to a discrete candidate angle (within the range [-90°, 90°], with discrete precision 0.1°). During the training phase, an improved learning rule adapted for multi-source scenarios is adopted: For input samples containing multiple signal sources, only the centroids corresponding to all true angles undergo forward updates (narrowing the distance from the query hypervector) and omit backward updates, avoiding multi-label conflicts; after training, all centroids are normalized to unit length. In the inference phase, by calculating the dot product similarity between the query hypervector and all trained centroids, an angle pseudo spectrum is generated.
4. Multi-source decoding employs non-maximum suppression algorithm to detect peaks in the pseudo spectrum, achieving multi-source DoA estimation: First, identify the maximum similarity angle, add it to the estimation set; then apply a suppression window (set as a minimum angle interval of 6° in this paper) around the identified angle, discarding similarity scores within the window; repeat this process until all M signal sources' DoAs are recognized, without matrix factorization, significantly reducing computational burden.
